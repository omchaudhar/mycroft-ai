**Defect DEF-EA14BE -- Response restates a governed figure incorrectly**

- Use case: `customer_support`, jurisdiction `IN`
- Signature: `hallucination:contradiction`
- Occurrences in the corpus: 16 of 264 traces
- Root cause: The generator restates a governed figure from memory instead of the retrieved document. Root cause is prompt-level: the system prompt does not require the answer to quote the retrieved policy.
- Estimated cost: Rs 354,787/month
- Pricing formula: rate 16/114 = 0.1404 x 12000 interactions/week x 4.33 weeks = 7292.6 occurrences/month; x (Rs 14.0 rework + 0.07 handoff rate x Rs 95.0 + Rs 28.0 churn exposure) per occurrence

## The fix

Require every answer to be backed by a governed document, so the assistant must refuse rather than improvise when the corpus does not cover the question.

```yaml
# customer_support@r1-b7cc3c4d4f  ->  customer_support@r2-5ae442dedc
patch: {'requirements': {'grounding_required': True}, 'revision': 2}
```
